# [Service Worker (sw.js)](../../../Frontend/Web/static/sw.js)

## Назначение
Service Worker — это фоновый скрипт, отвечающий за кэширование ресурсов, работу в оффлайн-режиме и оптимизацию скорости загрузки на медленных соединениях.

---

## Стратегии Кэширования

Скрипт реализует динамический выбор стратегии на основе типа контента и качества сети:

Навигация (`request.mode === 'navigate'`) всегда идёт через `networkFirst`, чтобы после деплоя F5 получал свежий `index.html` с новыми хэшами чанков. `/sw.js` всегда берётся из сети, POST и не-http запросы не перехватываются.

### 1. `cacheFirst` (Сначала кэш)
*   **Ресурсы**: изображения и JS/CSS чанки (у чанков уникальные хэши в именах).
*   **Логика**: Пытается взять файл из кэша. Если его там нет — загружает из сети и сохраняет в кэш.

### 2. `networkFirst` (Сначала сеть)
*   **Ресурсы**: HTML-навигация и `/api/`.
*   **Логика**: Для навигации сначала берёт `preloadResponse`, затем сеть. Если сеть недоступна — отдаёт сохранённую копию, а для навигации — закэшированный `index.html`.

### 3. `staleWhileRevalidate` (Устаревшее при проверке)
*   **Ресурсы**: всё остальное, включая шрифты и словари `/lang/`.
*   **Логика**: Мгновенно отдает кэш, но в фоновом режиме идет в сеть за обновлением.

---

## Оптимизация под соединение (`getEffectiveConnectionType`)
Скрипт умеет определять качество связи (`2g`, `3g`, `4g`):
*   На **медленных** соединениях (`slow-2g`, `2g`) SW переключается в режим `cacheOnly` для картинок, скриптов и стилей (в сеть идёт, только если в кэше пусто), API остаётся `networkFirst`, остальное — `cacheFirst`.

## Лимиты Кэша
*   **`MAX_DYNAMIC_CACHE_ENTRIES`**: 350. `trimCache(cacheName, maxEntries)` удаляет самые старые записи (FIFO), чтобы не переполнять память устройства.

## AI-контекст
*   SW использует `v5` префикс для названий кэшей, что позволяет выполнять «бесшовное» обновление при изменении логики (старый кэш удаляется в событии `activate`).
*   Сообщение `CACHE_UPDATED` от страницы своего origin запускает `trimCache` для динамического кэша (обрезает его до лимита, а не очищает полностью).
