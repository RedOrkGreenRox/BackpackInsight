# [Прокси сайта Leptos ([[path]].ts)](../../../Frontend/Web/functions/[[path]].ts)

## Назначение
Cloudflare Pages Function для всех путей сайта. Когда включена, пересылает страницы на сервер `RBackend` (бинарник `branches`). Сервер рендерит HTML через Leptos SSR, отдаёт WASM островов (`/pkg`) и серверные функции (`/_fn/*`). Pages остаётся спереди ради HTTPS и чтобы сервер не был виден напрямую.

## Включение
- Переменная окружения `LEPTOS_SSR=true` в настройках Pages. Без неё функция сразу вызывает `context.next()`, и Pages отдаёт статическую TS-версию из сборки, как раньше.
- `BACKEND` — адрес сервера (тот же, что у [api/[[path]]](api/[[path]].md)).
- `API_SECRET` — секрет; функция ставит его в `X-Internal-Secret`. Сервер с заданным секретом отвечает 403 на запросы без него, кроме открытых маршрутов `api` вроде `/health`.

## Что остаётся на Pages
- Префиксы `/images/`, `/fonts/`, `/lang/`.
- Файлы `/manifest.json`, `/robots.txt`, `/browserconfig.xml`.

Всё это отдаётся из сборки Pages без похода на сервер. Более точные функции `functions/api/*` и `functions/item/*` по правилам Pages срабатывают раньше этой.

## Заголовки
- Пересылаются все заголовки браузера, кроме `Host`:
  - `Cookie` (язык и фон);
  - `Accept-Language`;
  - `Islands-Router` (переход внутри сайта без перезагрузки).
- Пришедший от браузера `X-Internal-Secret` выбрасывается и заменяется настоящим.
- Редиректы не разворачиваются (`redirect: "manual"`): браузер получает их как есть.

## Сбои
Если сервер недоступен, возвращается `503` с текстом `RBackend offline: …`.
