# [Семантический поиск (SearchTermService.ts)](../../../../Frontend/Web/ground/utils/SearchTermService.ts)

## Назначение
Класс `SearchTermService` реализует сложную логику интеллектуального поиска. Он позволяет находить предметы не только по прямому вхождению, но и по синонимам, сокращениям и семантически близким терминам.

---

## Ключевая логика

### 1. Нормализация и Токенизация
Метод `normalizeText` подготавливает текст к анализу:
*   Разделяет camelCase (напр. «staminaRegen» → «stamina regen»), заменяет `_ / . -` на пробелы.
*   Удаляет пунктуацию и спецсимволы.
*   Удаляет диакритические знаки (акценты).
*   Заменяет `ё` на `е`.

### 2. Расширение запроса (Query Expansion)
Используя словарь алиасов `/search/term-aliases.ru.json` (загружается в `init()` один раз; при ошибке сети словарь пуст), сервис расширяет поисковой запрос:
*   Если пользователь ищет "хп", сервис добавит в поиск "здоровье", "health", "hp".
*   Каждому термину присваивается вес: 0 — слово из запроса, 0.08 — каноническое имя группы, 0.16 (или вес из словаря) — синоним, 0.18/+0.08 — совпадение по префиксу. Меньший вес — ближе к запросу; результаты расширения ограничены 32 терминами.

### 3. Семантическое ранжирование (`semanticRank`)
Алгоритм классифицирует совпадения по трем уровням:
*   **Rank 0**: Прямое вхождение токена в текст.
*   **Rank 1**: Вхождение одного из синонимов.
*   **Rank 2**: Совпадение не найдено.

### 4. Публичный API
*   `init()` — загрузка словаря и построение индекса (`buildIndex`). Вызывается из `ItemsDataLoader` в [ItemsBranch](../branches/items/ItemsBranch.md).
*   `normalizeText(text)`, `tokenize(text)` — нормализация и разбиение на токены.
*   `expandText(text)` — токены текста плюс все их синонимы одной строкой.
*   `expandQuery(query)`, `getExpandedQueryTerms(query)`, `getWeightedExpandedQueryTerms(query)` — расширенный запрос строкой, списком и списком `ExpandedQueryTerm` (`term`, `weight`, `isOriginal`).
*   `resolveCanonicalTerm(term)` — каноническое имя группы, к которой относится слово (или само нормализованное слово).
*   `extractStrictTerms(text)` — множество канонических терминов, встречающихся в тексте (для строгих тегов).
*   `semanticRank(text, query)` — ранг 0/1/2, см. выше.

Внутренние помощники: `buildWeightedTerms`, `indexWeightedTerms`, `expandToken` (точное совпадение или префикс от 4 символов), `getAliasTerm`, `getAliasWeight`, `textHasTokenLike`.

Потребители — модули поиска [managers/filter](../branches/items/_items/managers/filter/index.md).

## AI-контекст
*   Сервис строит внутренний индекс `tokenToExpansion` для O(1) поиска связанных терминов.
*   Поддерживает нечеткое сравнение префиксов (минимум 4 символа), что позволяет находить "poisonous" при поиске "poison".
