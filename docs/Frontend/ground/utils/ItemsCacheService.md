# [Кэш предметов (ItemsCacheService.ts)](../../../../Frontend/Web/ground/utils/ItemsCacheService.ts)

## Назначение
Единый кэш справочника предметов для `/items` и `/item/:name`. Держит каталог в памяти, переиспользует один запрос «в полёте» и дублирует справочник в sessionStorage (ключ `allItems.fb.v1`), чтобы он пережил переход между страницами.

## Методы (все статические)
*   **`getAllItems()`** — память → sessionStorage → запрос `ApiService.getItems()`. Пока запрос идёт, все вызовы получают один и тот же `Promise`.
*   **`setAllItems(items)`** — кладёт каталог в память и в sessionStorage.
*   **`getAllItemsFromCache()`** — синхронно отдаёт каталог из памяти или sessionStorage, без запроса; нет данных — `null`.
*   **`getBySlug(name)`** и **`getBySlugFromCache(name)`** — поиск предмета по имени или slug ([SlugService](SlugService.md)): первый при необходимости загружает каталог, второй смотрит только в кэш. Словаря нет, поиск идёт перебором массива.
*   **`clear()`** — сбрасывает память, текущий запрос и запись в sessionStorage.
*   **`readFromSessionStorage()`** / **`writeToSessionStorage(items)`** — чтение и запись с перехватом ошибок: недоступное хранилище или переполнение не ломают работу, остаётся кэш в памяти.
