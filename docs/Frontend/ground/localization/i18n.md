# [Локализация (i18n.ts)](../../../../Frontend/Web/ground/localization/i18n.ts)

## Назначение
Менеджер многоязычности. Отвечает за загрузку словарей и перевод строк интерфейса.

## Устройство
*   **`I18n`** — синглтон (`getInstance()`); наружу экспортируются экземпляр `i18n` и привязанная функция `t`.
*   **`init()`** — язык из `localStorage` (`lang`), иначе язык браузера, если это `ru` или `en`, иначе `en`. Если словарь не загрузился, откатывается на английский.
*   **`setLanguage(lang)`** — меняет язык, сохраняет выбор в `localStorage` и загружает словарь; повторный выбор того же языка ничего не делает. Перерисовку страницы делает вызывающий код.
*   **`loadLanguage(lang)`** — загружает `/lang/<lang>.json` ([словари](../../static/lang/index.md)); при ошибке HTTP бросает исключение.
*   **`t(key, ...args)`** — перевод по ключу; если ключа нет, возвращает сам ключ. Объект в первом аргументе заменяет именованные `{{имя}}`, иначе аргументы подставляются по позициям `{0}`, `{1}`.
