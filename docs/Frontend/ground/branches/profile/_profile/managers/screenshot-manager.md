# [Менеджер скриншотов (screenshot-manager.ts)](../../../../../../../Frontend/Web/ground/branches/profile/_profile/managers/screenshot-manager.ts)

## Назначение
`ScreenshotManager` сохраняет шапку профиля игрока (`.profile-header`) как PNG 900×600 по кнопке `#saveProfileBtn`. Рендер делает библиотека `html-to-image` (функция `toPng`), импортируемая статически.

## API
- `constructor(container, t)` — корневой элемент профиля и функция перевода (подписи кнопки).
- `init()` — вешает обработчик клика на `#saveProfileBtn`, если кнопка есть.
- `destroy()` — снимает обработчики.

## Как делается снимок (`takeScreenshot`, приватный)
1. Кнопка блокируется, текст меняется на `screenshot_saving`.
2. Шапка клонируется и фиксируется в левом верхнем углу размером 900×600 с `z-index: -9999`: клон рендерится браузером, но скрыт под контентом (за пределами экрана некоторые браузеры дают пустой холст).
3. В клоне каждый `<picture>` заменяется на его `<img>` (классы переносятся), относительные `src` превращаются в абсолютные; на ошибку загрузки картинка заменяется прозрачным PNG 1×1, чтобы `toPng` не падал. Предупреждение пишет локальная функция `logger_warn`.
4. После паузы 300 мс вызывается `toPng(clone, { backgroundColor: '#121212', width: 900, height: 600, cacheBust: true })`.
5. Клон удаляется, PNG скачивается через временную ссылку `profile-screenshot-<timestamp>.png`, кнопка возвращается в исходное состояние.
6. При ошибке кнопка показывает `screenshot_error`, а `showErrorNotification` выводит красное уведомление в правом верхнем углу на 3 секунды.
