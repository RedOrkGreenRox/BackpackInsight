# [Страница 404 (404/)](../../../../../Frontend/Web/ground/branches/404/)

## Назначение
Папка страницы для несуществующих адресов: случайный «редкостный» фон (шанс редкости как в игре) и кнопка возврата на главную.

## Состав
- [NotFoundBranch.ts](NotFoundBranch.md) — сборка страницы из `notFoundSpec`.
- [404.scss](404.md) — корневые стили.
- `_404/` — модули ([индекс](_404/index.md)): данные [NotFoundData](_404/data/NotFoundData.md), разметка [NotFoundDisplay](_404/display/NotFoundDisplay.md), логика [NotFoundLogic](_404/logic/NotFoundLogic.md), фон [background](_404/background/background.md), кнопка [button](_404/button/button.md), переход [navigation](_404/navigation/navigation.md), а также заголовок, текст, контейнер и оверлей.
