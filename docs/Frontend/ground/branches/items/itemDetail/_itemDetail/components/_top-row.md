# [Верхний ряд и описание (_top-row.scss)](../../../../../../../../Frontend/Web/ground/branches/items/itemDetail/_itemDetail/components/_top-row.scss)

## Назначение
Стили шапки карточки (иконка героя, название, редкость, теги) и блока описания предмета.

## Селекторы
- `.id-top-row` — grid из двух равных колонок.
- `.id-top-left` — левая колонка, прижимает иконку героя к левому верхнему углу.
- `.id-hero` — иконка связанного героя 128×128 без рамки; `.id-hero-empty` — полупрозрачная заглушка, когда герой не задан.
- `.id-top-right` — правая колонка: заголовок и теги друг под другом.
- `.id-title-wrap` — центрирует название и редкость.
- `.id-title` — название предмета (`h1`), адаптивный размер `clamp(1.3rem, 3.5vw, 1.8rem)`.
- `.id-rarity` — подпись редкости заглавными буквами; цвет даёт класс `rarity-*` из [_item-rarities](../../../../../roots/_roots/items/_item-rarities.md).
- `.id-tags` — вертикальный список типов предмета, прижат вправо и ограничен 50% ширины; иконки 18px.
- `.id-description` — описание во всю ширину: `white-space: pre-wrap`, иконки игровых терминов выровнены по строке текста, числовые значения (`.value-text` и любые классы с «value») подсвечены цветом заголовков.

## Связи
- Разметка: `renderTopRow` и `renderDescription` в [ItemDetailRenderer](ItemDetailRenderer.md).
- Уменьшение иконки героя на узких экранах — [_responsive](_responsive.md).
