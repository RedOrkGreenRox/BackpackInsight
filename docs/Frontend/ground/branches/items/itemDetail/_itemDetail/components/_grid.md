# [Сетка формы предмета (_grid.scss)](../../../../../../../../Frontend/Web/ground/branches/items/itemDetail/_itemDetail/components/_grid.scss)

## Назначение
Стили сетки формы предмета, которую генерирует [ItemGridRenderer](ItemGridRenderer.md). Количество столбцов/строк и пропорции задаются инлайн-стилями из рендерера; этот файл отвечает за слои и внешний вид.

## Селекторы
- `.id-grid` — CSS-grid не шире и не выше 280px, по центру колонки.
- `.id-grid-all-cells`, `.id-grid-stars` — обёртки с `display: contents`: их дети становятся прямыми элементами сетки.
- `.id-grid-cell` — клетка с тонкой лазурной рамкой; `.filled` — клетка, входящая в форму предмета (рамка ярче).
- `.id-grid-icon` — иконка предмета на всю сетку (`grid-column/row: 1 / -1`), `object-fit: contain`, тень, `z-index: 2`, не перехватывает клики.
- `.id-grid-star` — ячейка со звездой поверх иконки (`z-index: 3`).
- `.id-grid-star-icon` — иконка звезды 60% клетки с золотым свечением.
- `.id-grid-empty` — запасной вид, когда у предмета нет формы: картинка до 120px.
- `body.low-res-mode` — отключает тени и свечение у иконки и звёзд ([_low-res](../../../../../roots/_roots/_low-res.md)).
