# [Блок боевых характеристик (_stats.scss)](../../../../../../../../Frontend/Web/ground/branches/items/itemDetail/_itemDetail/components/_stats.scss)

## Назначение
Стили правой колонки карточки — боевых характеристик, которые строит `renderStatsList` в [ItemDetailParts](ItemDetailParts.md).

## Селекторы
- `.id-stats-block` — вертикальный flex, выравнивание по центру.
- `.id-stats-title` — заголовок «Статистика» (1.2rem, цвет заголовков).
- `.id-stat-row-h` — строка урона на всю ширину, выровнена по левому краю.
- `.id-stat-line` — строка из нескольких характеристик, центрирована, зазор 16px.
- `.id-stat-inline` — одна характеристика «иконка + значение».
- `.id-stat-icon` — контейнер иконки, картинка не больше 22px.
- `.id-stat-val` — значение характеристики (жирный белый).
