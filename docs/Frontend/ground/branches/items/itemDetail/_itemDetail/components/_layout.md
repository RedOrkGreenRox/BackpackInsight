# [Каркас карточки деталей (_layout.scss)](../../../../../../../../Frontend/Web/ground/branches/items/itemDetail/_itemDetail/components/_layout.scss)

## Назначение
Базовая раскладка подстраницы: контейнер, навигация, карточка, разделители, двухколоночный средний ряд и блок данных игрока. Разметку генерирует [ItemDetailRenderer](ItemDetailRenderer.md).

## Селекторы
- `.id-container` — центрированный контейнер шириной до `min(90vw, 1000px)` с отступом 20px.
- `.id-nav` — липкая (`position: sticky; top: 20px`) панель навигации над карточкой.
- `.id-nav-group` — flex-ряд из трёх кнопок, растянутый на всю ширину.
- `.id-nav-btn` — кнопка/ссылка навигации: тёмный фон, лазурная рамка, подсветка при наведении; модификатор `.disabled` — полупрозрачная и `cursor: not-allowed`.
- `.id-card` — сама карточка: тёмный полупрозрачный фон, радиус 16px, вертикальный flex с зазором 12px. Класс редкости (`rarity-*`) вешается на неё рендерером.
- `.id-divider` — горизонтальная линия с лазурным градиентом, исчезающим к краям.
- `.id-middle-row` — grid `1fr 1fr`: слева сетка формы, справа статы.
- `.id-left-col` — центрирует [сетку формы](_grid.md), минимальная высота 120px.
- `.id-right-col` — колонка статов (`min-width: 0` против переполнения).
- `.id-player-stats`, `.id-stat-row` — блок уровня и карт игрока из [ItemDetailParts](ItemDetailParts.md).
- `.stat-label` (приглушённый текст) и `.stat-value` (жирный; `.lvl` — лазурный цвет уровня).

Цвета берутся из CSS-переменных `--azure-raw` и `--text-default-color` ([_vars](../../../../../roots/_roots/_vars.md)).
