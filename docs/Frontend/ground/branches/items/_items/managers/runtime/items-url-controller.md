# [Поиск и фильтры в адресной строке (items-url-controller.ts)](/Frontend/Web/ground/branches/items/_items/managers/runtime/items-url-controller.ts)

## Назначение
`ItemsUrlController` — записывает текущий поиск и фильтры в адресную строку и показывает в поле поиска формулу, равную выбранным фильтрам.

## Методы
- `shareQuery()` — в расширенном режиме — текст поиска; в обычном — текст и формула фильтров через `&`.
- `buildConcreteFormula()` — формула из `FilterState` ([ItemsStateManager](../ItemsStateManager.md)): каждое значение — точный тег `[<…>]` (`mappedTag` убирает пробелы, «Melee Weapon» становится `MeleeWeapon`), несколько значений группы — через `|` в круглых скобках, исключения — с `!`, флаг покупаемости — `[<Purchasable>]` или `![<Purchasable>]`.
- `normalizeShareQuery(query)` — убирает пробелы вокруг операторов и скобок и переводит в нижний регистр.
- `syncUrl()` — заменяет адрес на `/items/<запрос>` (или `/items`) через `history.replaceState`, без новой записи в истории.
- `renderSearchFilterPreview()` — в обычном режиме кладёт формулу в `data-filter-query` поля `#itemSearch`; стили показывают её подсказкой.

Обратного чтения нет: [ItemsBranch](../../../ItemsBranch.md) берёт из адреса только параметры `?item=` и `?search=`, а маршрут `/items/<запрос>` в [core](../../../../../core.md) не зарегистрирован, и роутер показывает на нём страницу 404 — например, при перезагрузке страницы с активным поиском.
