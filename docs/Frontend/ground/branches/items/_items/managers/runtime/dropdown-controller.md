# [dropdown-controller.ts](/Frontend/Web/ground/branches/items/_items/managers/runtime/dropdown-controller.ts)

## Назначение
`DropdownController` — сворачиваемые категории панели фильтров. Каждая кнопка `.dropdown-toggle` с `data-target` управляет блоком с этим id.

## Методы
- `init()` — при загрузке **раскрывает** все категории (`open`) и вешает обработчики клика.
- `onClick(e, toggle)` — переключает класс `show` у блока и `open` у кнопки, меняет стрелку `.dropdown-arrow` (▲ — открыто, ▼ — закрыто).
- `open(toggle)` — открывает блок без проверки текущего состояния.

Состояние категорий не сохраняется: после перехода на страницу все снова раскрыты.
