# [alias-fuzzy.ts](/Frontend/Web/ground/branches/items/_items/managers/filter/alias-fuzzy.ts)

## Назначение
`expandAliasTerm(raw)` — раскрывает поисковый терм в набор синонимов с весами по словарю [term-aliases.ru.json](../../../../../../static/search/term-aliases.ru.md). Позволяет искать, например, по русскому слову предметы с английским описанием.

## Типы
- `AliasEntry` — алиас строкой или объектом `{ term, weight }`; `AliasMap` — канонический терм → список алиасов.
- `AliasDoc` — запись индекса: `term`, `canonical`, `weight`.
- `AliasExpansion` — результат: `value` и `weight`.

## Алгоритм
1. Терм нормализуется `SearchTermService.normalizeText` ([SearchTermService](../../../../../utils/SearchTermService.md)); пустой — пустой результат.
2. Сам терм получает вес 1.
3. Точные совпадения с алиасом или каноном (`exact`) добавляют канон с весом алиаса и сам алиас с весом × 0.92 (`addDoc`).
4. Для термов от 4 символов — до 8 нечётких совпадений Fuse (`fuzzy`, порог 0.38) с множителем `1 − score`, не меньше 0.25.
5. Для каждого значения сохраняется наибольший вес (`add`).

## Внутреннее
- `ensureIndex` — строит индекс один раз за сессию; `buildDocs` — записи из словаря; `dedupe` — одна запись на пару «алиас, канон» с наибольшим весом.
- `aliasTerm`, `aliasWeight` — текст и вес алиаса; вес по умолчанию 0.92.
