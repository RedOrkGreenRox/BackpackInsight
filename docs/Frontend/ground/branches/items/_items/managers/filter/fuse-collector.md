# [Нечёткий поиск по термам (fuse-collector.ts)](/Frontend/Web/ground/branches/items/_items/managers/filter/fuse-collector.ts)

## Назначение
`applyFuseSearch(items, terms, groupCount, fuse)` — нечёткий поиск по взвешенным термам плана ([search-plan](search-plan.md)). Возвращает только предметы, которые совпали хотя бы с одним термом **каждой** группы, по убыванию суммарной оценки; оценка записывается в предмет ([search-score](search-score.md)). Без индекса возвращает список как есть.

## Подсчёт оценки
Для каждого результата Fuse по терму (`collectFuseScores`):
1. Предмет должен быть во входном списке, а короткий терм — совпадать целым словом (`shortTermMatches`, [fuzzy-term-guard](fuzzy-term-guard.md)).
2. База — `(1 − score) × вес терма × fuzzyMultiplier`. `fuzzyMultiplier` равен 1, если терм есть целым словом в тексте предмета, иначе 0.18 (так «skull» почти не поднимает «skullduggery»).
3. `exactFieldBonus` — целое слово в имени +1.2 веса, в типах или строгих тегах +1.8, в подсказке +0.25, в имени и тегах сразу ещё +1.35.
4. Первое совпадение в группе прибавляется целиком; повторные в той же группе — только на 15 %.

## Внутреннее
- `normalizeSingle(value)` — терм в нижнем регистре, если это одно слово, иначе пустая строка (бонусы не начисляются).
- `hasWord(text, token)` — проверка целого слова.
- `FuseLike`, `FuseResult`, `ScoreEntry` — минимальные типы для индекса и накопителя.
