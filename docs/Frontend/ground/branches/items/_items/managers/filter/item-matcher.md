# [Проверка строгих условий поиска (item-matcher.ts)](/Frontend/Web/ground/branches/items/_items/managers/filter/item-matcher.ts)

## Назначение
`ItemMatcher` — проверка строгих условий поиска и фильтров панели по подготовленным данным предмета (`preparedByKey`, см. [prepared-items](prepared-items.md)).

## Публичные методы
- `matchAST(item, ast)` — все узлы верхнего уровня должны совпасть.
- `itemMatchesStrictTag(item, tag)` — совпадает ли предмет с тегом; проверки по порядку:
  1. нормализованный тег или его слитная форма есть среди слов предмета (имя, типы, герой, ключи характеристик, подсказки) или строгих токенов;
  2. все слова многословного тега есть среди этих слов;
  3. тег встречается в тексте подсказок (`tooltipContains`);
  4. канонический термин (`SearchTermService.resolveCanonicalTerm`) есть среди извлечённых строгих терминов.
  Отдельное правило: тег «buff» не совпадает с предметом, у которого есть только «debuff».

## Внутреннее
- `matchASTNode` — `and` / `or` / лист, затем отрицание узла.
- `matchesToken` — сравнение ([comparison](comparison.md)), точное совпадение или тег. Пустой терм истинен, если узел не отрицательный.
- `matchesExact(item, term)` — слаг героя, типа (с дефисами и без) или редкости равен терму, либо терм `purchasable` у покупаемого предмета. Слаги — [SlugService](../../../../../utils/SlugService.md).
- `getPrepared(item)` — подготовленные данные по ключу.
