# [Стили rich-чипов](../../../../../../../Frontend/Web/ground/branches/items/_items/search/_rich-token.scss)

## Назначение
Описывает визуальные состояния фильтр-чипов: обычный, exact, negated и focused.

## Селекторы
Все правила вложены в `.search-input-rich`.
- `.rich-token` — капсула условия. Модификаторы: `.plain` (обычный, прозрачный), `.exact` (зелёный, точное совпадение), `.negated` (красный, исключение; перекрывает остальные), `.focused-token` (белая подсветка и лёгкое увеличение у выбранного с клавиатуры).
- `.token-close-btn` — крестик удаления внутри капсулы, проявляется при наведении.
- `.filter-icon` — иконка 18×18 внутри капсулы (картинка вписывается целиком).
