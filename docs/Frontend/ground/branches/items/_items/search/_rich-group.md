# [Стили rich-групп](../../../../../../../Frontend/Web/ground/branches/items/_items/search/_rich-group.scss)

## Назначение
Описывает визуальный контейнер логической группы `[...]`: жёлтый акцент, вложенные группы и компактный режим для глубокой вложенности.

## Селекторы
Все правила вложены в `.search-input-rich` (rich-поле поиска).
- `.rich-group` — капсула группы с жёлтой рамкой и фоном; вложенные группы второго уровня компактнее, третьего — с пунктирной рамкой и чуть меньшим шрифтом.
- `.group-bracket` — сами скобки группы, жёлтые и жирные.
