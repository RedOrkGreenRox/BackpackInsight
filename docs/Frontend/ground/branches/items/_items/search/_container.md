# [Контейнер поиска (_container.scss)](../../../../../../../Frontend/Web/ground/branches/items/_items/search/_container.scss)

## Назначение
Стилизация внешней обертки для поля поиска предметов.

## Характеристики
*   **`.search-container`** — внешний блок поиска: ширина до `1100px` (во всю ширину контента), центрирование, `z-index: 100`, чтобы выпадающие панели лежали поверх сетки.
*   **`.search-input-wrapper`** — «таблетка» поля: полупрозрачный фон, скругление `50px`, лазурная подсветка при фокусе (`:focus-within`). С классом `.open` нижние углы становятся прямыми, и поле сливается с открытой панелью фильтров.
*   **`.search-input`** внутри обёртки — прозрачное поле без рамки, справа отступ под кнопку фильтров.
*   **`.filter-toggle-btn`** — круглая иконка-кнопка справа, лёгкий зум при наведении, подсветка в состоянии `.open`.
*   **`.filter-toggle-icon`** — стрелка в кнопке; при `.open` разворачивается на 180°.
