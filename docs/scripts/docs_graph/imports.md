# [Импорты кода для графа (imports.py)](../../../scripts/docs_graph/imports.py)

## Назначение
Находит, какой исходник репозитория подключает какой: из этого граф строит связи «импорт в коде». Разбор по регулярным выражениям, без компиляторов; ссылки на внешние пакеты отбрасываются.

## Функции
- **`imports(sources)`** — исходник → множество исходников репозитория, которые он подключает. Rust разбирает [rust_imports.py](rust_imports.md), остальные языки — функции ниже.
- **`_ts(src, text)`** — TS и JS: `import … from`, `export … from`, `import()` и `require()` с относительным путём; путь дополняется `.ts`, `.js` или `index.ts`.
- **`_scss(src, text)`** — `@use`, `@forward`, `@import`: файл `x.scss`, частичный `_x.scss` или `x/_index.scss`. Встроенные модули `sass:` пропускаются.
- **`_py(src, text)`** — `import x` и `from .x import y`: относительный импорт от папки файла, абсолютный — от папки файла и её родителя (так скрипты в `scripts/` подключают `docs_lint`).
- **`_first(*paths)`** — первый существующий файл из вариантов.
