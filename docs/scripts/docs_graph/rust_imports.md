# [Импорты Rust для графа (rust_imports.py)](../../../scripts/docs_graph/rust_imports.py)

## Назначение
Переводит `mod` и `use` в файлы модулей репозитория, чтобы граф показал зависимости между Rust-исходниками и крейтами.

## Ключевое
- **`RustCrates`** — крейты репозитория: имя пакета из `Cargo.toml` (дефисы → подчёркивания) → его папка `src`. `crate_of(path)` — крейт файла.
- **`rust_imports(src, text, crates)`** — файлы, которые подключает исходник: `mod x;` (соседний `x.rs` или `x/mod.rs`), `use crate::…`, `self::…`, `super::…` и `use <крейт>::…`, а также полные пути вида `api::serve()` в теле кода (так `main.rs` связан со своим `lib.rs`). Комментарии вырезаются заранее.
- **`_rs_module_dir(src)`** — папка подмодулей файла: у `lib.rs`, `main.rs` и `mod.rs` — его папка, у прочих — папка с именем файла.
- **`_rs_walk(start, parts)`** — самый глубокий файл модуля по сегментам пути: `a::b::C` даёт `a/b.rs`, если `C` — элемент, а не модуль.
- **`_rs_paths(tree)`** — раскрывает группы: `a::{b, c::d}` → `a::b` и `a::c::d`.

## Связи
- Вызывается из [imports.py](imports.md).
