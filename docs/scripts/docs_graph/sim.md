# [Раскладка графа (sim.js)](../../../scripts/docs_graph/sim.js)

## Назначение
Модель графа и силовая раскладка без библиотек: документы отталкиваются, связи стягивают их пружинами, а кластеры из [pack.js](pack.md) держат свои скопления.

## Ключевое
- **`ZONES`** — папки доков (`rust`, `ts`, `py` — пустая со времён Python-бэкенда, `tools`, `meta`): подпись и цвет ореола звезды из CSS-переменной страницы.
- **`LANGS`** — языки описываемых файлов (`rust`, `ts`, `scss`, `py`, `data`, `doc`): подпись и цвет ядра звезды.
- **`KINDS`** — виды связей по битовой маске: `3` ссылка и импорт, `1` только ссылка в доке, `2` только импорт в коде; подпись и цвет. `BAD` — CSS-переменная красного цвета проблем.
- **`G`** — общее состояние: узлы, связи, `byId`, скрытые зоны, языки и виды связей (`hiddenLangs`, `hiddenKinds`), `showHubs`, «температура» `alpha`, колбэк `onTick`, корень кластеров `root`.
- **`rng(seed)`** — детерминированный генератор: стартовая раскладка одинакова при каждом открытии.
- **`buildGraph(data)`** — цвета из CSS, узлы, связи с видом `k`, списки `out`/`inc`, степень `deg` и радиус звезды (растёт как корень из числа связей). Стартовые координаты ставит `repack` из [pack.js](pack.md).
- **`visible(n)`** и **`edgeOn(e)`** — узел виден, если не скрыты ни его зона, ни язык, и он не карта (или карты включены); связь видна, если не скрыт её вид и видны оба конца.
- **`tick()`** — один шаг: отталкивание пар ближе 90 единиц (сила ∝ 1/d², только местное, чтобы не разрывать кластеры), пружины длиной 46 с весом, обратным корню из степени; между разными кластерами пружина почти не тянет и ещё делится на степень, чтобы индекс папки со ста ссылками не уходил из своего кластера. Притяжение к центру своего диска: внутри слабое, за краем жёсткое. Затухание скорости 0.62 и ограничение скорости; `alpha` остывает в 0.985 раза за шаг.
- **`reheat(a)`** — подогревает раскладку после перетаскивания или смены фильтров.
- **`settle(steps)`** — прогон до первого кадра, чтобы страница открывалась уже собранным графом.
- **`runSim()`** — цикл `requestAnimationFrame`: считает шаг, пока граф не остыл, и зовёт `onTick`.
