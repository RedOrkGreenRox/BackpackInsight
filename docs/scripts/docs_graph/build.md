# [Сборщик графа документации (docs_graph/build.py)](../../../scripts/docs_graph/build.py)

## Назначение
Собирает отдельную от сайта статичную страницу «Созвездие документации»: все документы `docs/` и `README.md` как звёзды, ссылки между ними как линии. Получается один HTML-файл, которому не нужен сервер: данные и скрипты встроены в него.

## Запуск
`python3 scripts/docs_graph/build.py [файл.html] [--fragment]` из любой папки (скрипт сам переходит в корень). По умолчанию пишет `target/docs-graph.html` (папка `target` в `.gitignore`). С `--fragment` пишет страницу без `<!doctype>` и `<head>`: в таком виде её принимает публикация Artifact, которая сама добавляет каркас.

## Функции
- **`collect()`** — узлы и связи. Узел: путь, заголовок, зона, признак карты (`hub`), исходник из H1 (`src`) и полный текст. Связь — ссылка документа на другой документ (без ссылок на себя и на исходники); ссылки ищет `link_targets` из [files.py](../docs_lint/files.md), поэтому примеры в `` `…` `` не считаются.
- **`zone(path)`** — зона по префиксу пути из `ZONES`: `rust` (RBackend), `ts` (старый фронтенд), `py` (Python), `tools` (скрипты и данные), иначе `meta`.
- **`title(path, text)`** — текст H1 без ссылки; без H1 — имя файла.
- **`source_of(path)`** — куда ведёт ссылка в H1 (файл или папка).
- **`page(data, fragment)`** — подставляет JSON вместо `/*DATA*/` и скрипты `SCRIPTS` вместо `/*SCRIPTS*/` в `page.html`; каждый `<` в данных заменяется на `\u003c`, чтобы текст документа не закрыл и не сломал `<script>`. Скрипты подставляются раньше данных: сами маркеры встречаются в тексте документов (в том числе в этом). Без `fragment` оборачивает страницу в `HEAD`.
- **`main()`** — пишет файл и печатает число документов и связей.

## Константы
- `HUBS` — `docs/structure.md` и `README.md`. Они ссылаются почти на всё, поэтому на странице по умолчанию скрыты, иначе граф слипается в один ком.
