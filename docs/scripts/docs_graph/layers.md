# [Фоновые слои графа (layers.js)](../../../scripts/docs_graph/layers.js)

## Назначение
Рисует под звёздами контуры кластеров с подписями и связи трёх видов.

## Функции
- **`drawGroups(ctx, toScreenXY, k)`** — круги кластеров: верхний уровень всегда, вложенные (пунктиром) по мере приближения. Подпись — имя папки и вес: у большого круга внутри у верхней кромки, у маленького над ним. Кластер «Проблемы» и его подкластеры красные. Свои звёзды корня `docs/` подписаны отдельно.
- **`drawEdges(ctx, toScreen, k, f, focus)`** — связи по видам `KINDS`: «ссылка и импорт» толще, «только ссылка» тусклее, «только импорт» пунктиром (зависимость в коде, о которой молчит документация). У звезды в фокусе связи яркие, у остальных приглушены.

## Связи
- Вызывается из `draw()` в [view.js](view.md); геометрия кластеров — [pack.js](pack.md).
