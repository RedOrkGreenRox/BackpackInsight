# [Данные графа документации (collect.py)](../../../scripts/docs_graph/collect.py)

## Назначение
Готовит данные для страницы графа: узлы, связи трёх видов, проблемы каждого узла и путь его кластера.

## Функции
- **`collect()`** — узлы и связи. Узел — документ `docs/` или `README.md`: путь, заголовок, зона (папка), язык исходника (`lang`), признак карты (`hub`), исходник из H1 (`src`), полный текст, список проблем (`bad`) и путь кластера (`group`). Исходник без зеркального дока тоже становится узлом (`code`), сразу в кластере проблем. Связь `[s, t, k]`, где `k` — битовая маска: `LINK` — ссылка дока на док (ищет `link_targets` из [files.py](../docs_lint/files.md), примеры в `` `…` `` не считаются), `IMPORT` — исходник одного дока подключает исходник другого (из [imports.py](imports.md)), `3` — и то и другое.
- **`group_of(path, problems)`** — путь кластера: папки дока без `docs/` (не глубже `MAX_DEPTH`), у исходника — его папки. У проблемного узла — `Проблемы` и первая причина.
- **`zone(path)`** — зона по префиксу пути из `ZONES`: `rust` (Backend), `ts` (старый фронтенд), `tools` (скрипты и данные), иначе `meta`.
- **`lang(src)`** — язык описываемого файла по расширению из `LANGS`: `rust`, `ts` (TS и JS), `scss`, `py` (Python и PowerShell); прочие файлы — `data`, папки и доки без исходника — `doc`.
- **`title(path, text)`** — текст H1 без ссылки; без H1 — имя файла.
- **`source_of(path)`** — куда ведёт ссылка в H1 (файл или папка).

## Константы
- `HUBS` — `docs/structure.md` и `README.md`. Они ссылаются почти на всё, поэтому на странице по умолчанию скрыты, иначе граф слипается в один ком.
- `LINK`, `IMPORT` — биты вида связи. Связь только одного вида показывает, где документация и код расходятся.
- `MAX_DEPTH` — 5 уровней вложенности кластеров; более глубокие папки сливаются в предка.
