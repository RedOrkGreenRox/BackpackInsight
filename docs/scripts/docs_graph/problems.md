# [Проблемы документации для графа (problems.py)](../../../scripts/docs_graph/problems.py)

## Назначение
Отмечает узлы графа, с которыми что-то не так: такие звёзды рисуются красным и собираются в отдельный кластер «Проблемы», подкластеры которого — причины.

## Функции
- **`doc_problems(docs, hubs)`** — документ → список причин по порядку `ORDER`: `BROKEN` (битые ссылки, как в `check_links`), `UNREACHABLE` (недостижим от README, как в `check_tree`), `ORPHAN` (ссылаются только карты), `NO_SOURCE` (H1 ведёт на удалённый файл), `DUPLICATE` (у исходника два зеркала).
- **`orphans(docs, hubs)`** — доки без смысловых входящих ссылок: на них ссылаются только `README.md` и `docs/structure.md`.
- **`missing_mirrors()`** — исходники без зеркального дока (`NO_MIRROR`), из `check_mirror`.
- **`mirror_index()`** — исходник → его зеркальный документ, чтобы импорты кода превратить в связи между доками.

## Связи
- Проверки берутся из [graph.py](../docs_lint/graph.md) и [mirror.py](../docs_lint/mirror.md); данные собирает [collect.py](collect.md).
