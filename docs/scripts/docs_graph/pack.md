# [Кластеры графа (pack.js)](../../../scripts/docs_graph/pack.js)

## Назначение
Строит дерево кластеров по папкам и раскладывает их кругами: вложенные папки — подкластеры, тяжёлые группы в середине, лёгкие по краю, между соседними кругами зазор, поэтому группы расходятся друг от друга.

## Ключевое
- **`buildGroups()`** — дерево групп из пути `group` каждого узла; узел получает свою группу `g`.
- **`packCircles(items, gap)`** — плотная упаковка: круги идут от тяжёлых к лёгким, каждый касается одного или двух уже поставленных и встаёт ближе всего к центру. Потом группа центрируется по габариту; возвращает её радиус.
- **`measure(g)`** — снизу вверх: вес группы (число видимых звёзд в ней и вложенных), радиус её диска своих звёзд `or` и радиус всей группы `r`. «Проблемы» всегда последние.
- **`place(g, x, y)`** — сверху вниз: центр группы (`cx`, `cy`) и её диска звёзд (`ox`, `oy`).
- **`repack(first)`** — пересчёт под текущие фильтры (скрытые звёзды не весят); при первом вызове звёзды расставляются по своим дискам.
- **`isProblem(g)`** — верхняя группа «Проблемы».

## Константы
- `NODE_AREA` — радиус диска растёт как `NODE_AREA·√(звёзд)`.
- `GAPS` — зазор между кругами по глубине: верхние группы расходятся сильнее вложенных.
- `PROBLEM_GAP` — кластер «Проблемы» держится дальше остальных.

## Связи
- Звёзды тянет к их дискам [sim.js](sim.md); контуры рисует [layers.js](layers.md); вызывает [panel.js](panel.md).
