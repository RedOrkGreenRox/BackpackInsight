# [Генератор карты (generate_structure.py)](../../scripts/generate_structure.py)

## Назначение
Скрипт `generate_structure.py` автоматически создает и обновляет файл [docs/structure.md](../structure.md). Он служит для визуализации иерархии проекта и навигации по документации.

---

## Возможности

1.  **Индикация состояния**: 
    *   `📄` — файл задокументирован.
    *   `❌` — документация отсутствует (`MISSING DOC`).
    *   `🗃` — `.md` и `.json` без зеркального документа: документация и данные, которым зеркало не нужно (`REQUIREMENTS.md` §2).
2.  **Человекочитаемые имена**: Скрипт использует словарь `BEAUTIFUL_NAMES` для замены технических имен файлов и папок на понятные заголовки (например, `PlayerData` -> `Логика игроков и предметов`).
3.  **Умная фильтрация**: Скрывает служебные папки (`.git`, `node_modules`, `__pycache__`), сборку Cargo (`target`) и генерируемый код (`generated`) и ассеты (картинки, шрифты), если они не имеют собственного файла описания.
4.  **Кликабельные папки**: Если у папки есть вводный файл `index.md`, название папки в дереве становится ссылкой.
5.  **`render()` и `main()`**: `render()` возвращает текст карты, `main()` записывает его в `docs/structure.md`. [check_docs.py](check_docs.md) вызывает `render()` и сравнивает с файлом (проверка `FRESH`).

---

## Функции
*   **`find_doc_file(relative_path)`** — ищет документ для пути исходника: убирает `Web` из `Frontend/Web/…`, спускается по папкам `docs/` без учёта регистра и пробует имена `имя_ts.md` (для `.ts`, `.py`, `.js`), `имя.md` и `файл.расширение.md`. Для папки вызывается с `index.ts`, поэтому находит её `index.md`. Нет документа — `None`.
*   **`tracked_paths()`** — файлы под git и все их родительские папки. В дерево попадает только то, что отслеживает git; вне git — `None`, и фильтр не применяется.
*   **`generate_list_tree(dir_path, current_rel_path, indent)`** — рекурсивно строит строки дерева: сначала папки, потом файлы; пропускает `IGNORE_DIRS`/`IGNORE_FILES`; даёт особые имена `[id].ts`, `[[path]].ts` и версионным `items_X_Y_Z.json`; ставит значки `📄`/`🗃`/`❌`, а ассеты без документа скрывает.

---

## Исключения
*   `REQUIREMENTS.md` — свод правил, не является исходным кодом и не включается в `docs/structure.md`.

## AI-контекст
*   Скрипт автоматически обрабатывает переименование файлов. После любого перемещения файлов в проекте запустите этот скрипт, чтобы обновить карту ссылок.
*   Поддерживает поиск документации даже при различии в регистре имен (например, `api.py` -> `api.md`).
