# [docs_lint/mirror.py](/scripts/docs_lint/mirror.py)

## Назначение
Принцип 1:1 и правила оформления документов (`ARENA.MD` §1.2, §1.6, §1.7, §2.1): проверки `MIRROR` и `STRUCT`.

## Ключевое
- **`check_mirror()`** — исходники без документа, чей H1 ведёт на них (кроме `__init__.py`), и исходники, на которые H1 ведут несколько документов. Простая ссылка из чужого документа зеркалом не считается.
- **`check_struct()`** — возвращает (ошибки, предупреждения):
  - ошибка: у документа с H1 на файл (не `.md`) нет раздела `## …Назначение`;
  - ошибка: нет подписи `SIGNATURE` или она не в последних двух строках;
  - ошибка: больше `LINES_FAIL` (250) строк, предупреждение: больше `LINES_WARN` (150). `GENERATED_DOCS` (карта `docs/structure.md`) не проверяются на длину;
  - предупреждение: строки с обещаниями вне разделов «Планируется» и «В разработке».
- **`planning_lines(text)`** — номера таких строк. `PLANNING_RE` ищет «будем», «планируем», «скоро», «в будущем», `TODO`, `FIXME` и «будет добавлен/реализован/…». Обычное «будет» в описании следствий не считается.
