# [docs_lint/graph.py](/scripts/docs_lint/graph.py)

## Назначение
Связность сети документов: проверки `LINKS`, `TREE` и `FRESH` для [check_docs.py](../check_docs.md).

## Ключевое
- **`slug(heading)`** — якорь заголовка по правилам GitHub: текст ссылок без адреса, нижний регистр, без знаков препинания, пробелы → дефисы.
- **`anchors(md)`** — все якоря заголовков документа.
- **`check_links()`** — для всех документов и `README.md`: ссылка на несуществующий путь или на `.md` с якорем, которого там нет.
- **`check_tree()`** — обход в ширину от `README.md` и `docs/structure.md` (центральные узлы по `ARENA.MD` §1.4). Возвращает сирот, число достижимых и общее число документов.
- **`check_fresh()`** — загружает [generate_structure.py](../generate_structure.md) и сравнивает результат его `render()` с `docs/structure.md`.
