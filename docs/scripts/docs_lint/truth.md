# [docs_lint/truth.py](/scripts/docs_lint/truth.py)

## Назначение
Сверка текста документа с кодом: проверки `COMPLETE` (документ описывает свой исходник) и `TRUTH` (документ не выдумывает имена).

## Ключевое
- **`check()`** — для каждого документа из `doc_source_map`:
  - `COMPLETE`: если у исходника ≥ 3 символов и документ упоминает меньше `COMPLETE_MIN` (50 %), документ попадает в список с долей и первыми пропущенными именами. `SYM_IGNORE` — служебные имена (`init`, `render`, тестовые `describe`/`it`…), их не требуют;
  - `TRUTH`: имена из `` `…` ``, которых нет ни в связанных исходниках, ни среди символов всего кода.
- **`mentions(text, token)`** — вхождение как отдельного слова: `getItem` не находится внутри `getItemsFromCache`.
- **`related_sources(doc, own)`** — исходник документа, исходники из его ссылок и исходники документов, на которые он ссылается (один шаг). Так документ может назвать функцию соседнего модуля, если ссылается на его документ.
- **`claimed_tokens(text)`** — что документ показывает как код: идентификаторы от 4 символов и `.класс`/`#id`. Пропускаются хэши коммитов, расширения файлов (`.ts`), общие слова `COMMON` и строка подписи.
