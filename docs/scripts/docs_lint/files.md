# [Файлы и ссылки линтера (files.py)](/scripts/docs_lint/files.py)

## Назначение
Общий слой линтера: какие файлы считать документами и исходниками, как читать ссылки и куда они ведут. Остальные модули пакета не обходят диск сами.

## Ключевое
- **`ROOT`**, **`DOCS`** — корень репозитория и папка `docs`.
- **`SRC_EXT`** — расширения исходников, которым нужно зеркало по `ARENA.MD` §1.2: `.py`, `.ts`, `.scss`, `.js`, `.cjs`, `.mjs`, `.rs`, `.sql`, `.mako`, `.fbs`. **`SRC_NAMES`** — исходники по имени: `Cargo.toml`, `rust-toolchain.toml`.
- **`SKIP_DIRS`** — папки без зеркал: служебные, сборка (`target`, `dist`), зависимости и код, который генерируют flatc и builder (`generated`).
- **`read(path)`** — текст файла; при ошибке чтения или кодировки — пустая строка.
- **`is_source(path)`** — подходит ли файл под `SRC_EXT` или `SRC_NAMES`.
- **`tracked_files()`** — файлы под git (`git ls-files`), чтобы мусор рабочей копии не влиял на проверку; вне git — обход диска без `SKIP_DIRS`.
- **`all_docs()`**, **`all_sources()`** — все `.md` в `docs/` и все исходники под git вне `SKIP_DIRS`.
- **`link_targets(md)`** — цели ссылок документа без внешних адресов. Примеры в блоках кода и в `` `…` `` не считаются ссылками (`CODE_RE`).
- **`resolve(md, target)`** — путь цели: `/…` от корня репозитория, иначе от папки документа; якорь отбрасывается.
- **`h1_target(md)`** — файл из ссылки в заголовке первой строки.
- **`doc_source_map()`** — документ → исходник из его H1, только для исходников.
- **`SIGNATURE`** — начало строки подписи документации.
