# [Пример переменных окружения (.env.example)](../.env.example)

## Назначение
Файл `.env.example` служит шаблоном для локального файла `.env`. Содержит переменные окружения, которые требуются для работы Rust-бэкенда `RBackend/` и фронтенда.

## Ключевые параметры

### 1. База данных (PostgreSQL/SQLite)
*   **`POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` / `POSTGRES_PORT`**: учётные данные и порт для PostgreSQL.
*   **`ROOT_DB_ENABLED`**: `true` — подключить SQLx-пул (`RBackend/crates/db/src/lib.rs`); `false` (по умолчанию) — профиль сохраняется только в памяти.
*   **`ROOT_DB_URL`**: прямая строка подключения (переопределяет `POSTGRES_*`).

### 2. API-сервер
*   **`ROOT_API_ADDR`**: адрес слушателя Axum (по умолчанию `127.0.0.1:8090`).
*   **`ROOT_API_SECRET`** (или `API_SECRET`): секрет для защищённых FlatBuffer-эндпоинтов `POST /api/profile.fb` и `GET /api/items.fb`.
*   **`ROOT_ENV`**: `production` требует `ROOT_API_SECRET` (или `ROOT_ALLOW_NO_SECRET=true`).
*   **`ROOT_PROFILE_RATE_LIMIT`**: лимит запросов профиля (по умолчанию `20/мин`).
*   **`ROOT_CORS_ORIGIN`** (или `CORS_ORIGIN`): разрешённый источник фронтенда.

### 3. Прочие
*   **`ROOT_PUBLIC_BASE_URL`**: публичный URL для sitemap/robots.
*   **`ROOT_PROJECT_ROOT`**: путь к корню репозитория (иначе авто-обнаружение).
*   **`RUST_LOG`**: уровень трассировки (`info` по умолчанию).

## Связи
*   Разбор переменных: [state.rs](RBackend/crates/api/src/state.md).
*   Рабочий процесс запуска: [main.rs](RBackend/crates/api/src/main.md).
