# [Проверка нового ContentKit (check.rs)](/Backend/crates/art/src/check.rs)

## Назначение
`art check`: резолв без кодирования — быстрый ответ, готов ли новый ContentKit.

## API
- **`CheckReport`** — версия игры, `resolved`, `missing_by_rule`, `unresolved` (ошибки резолва: предмету нужна строка в правилах), `slug_clashes` (разные `id` с одинаковым slug), `unused` (картинки архива, не нужные ни одному предмету; относительно корня архива, отсортированы). `Display` печатает сводку и списки.
- **`check(kit, export, rules)`** — ошибка только если экспорт или архив не читаются; непокрытые предметы — часть отчёта.

## Связи
- [kit.rs](kit.md), [resolve.rs](resolve.md); вызывающий — [main.rs](main.md).
