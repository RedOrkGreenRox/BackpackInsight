# [Волна по соседям капли (drop_wave.rs)](/Backend/crates/branches/src/shell/drop_wave.rs)

## Назначение
Когда меню закрыто, пункт в фокусе выпускает из края экрана «каплю» ([_nav-drop.scss](../../style/roots/_roots/shell/sidebar/_nav-drop.md)). Этот модуль заставляет соседние пункты ответить затухающей волной: их капли коротко выглядывают из края, и чем дальше сосед, тем позже и слабее. Волна идёт и при выходе капли, и при её возврате. Только в сборке `hydrate`; обработчики вешает [sidebar.rs](sidebar.md).

## Ключевая функциональность
- **`on_focus_in(ev)`** — фокус пришёл в пункт закрытого меню (`#sidebar:not(.open) .nav-tab`): волна вокруг него.
- **`on_focus_out(ev)`** — фокус ушёл из меню совсем (`relatedTarget` не пункт меню): волна вокруг покинутого пункта. Переход на соседний пункт обрабатывает `focusin`.
- **`ripple_around(tab)`** (приватная) — обходит все `#sidebar .nav-tab` (включая ссылку языка). Своей капле снимает волну (`stop_wave`), соседям на расстоянии 1 и 2 запускает `wave` с амплитудой из `AMPLITUDES` (55% и 25% ширины) и задержкой `STEP_MS` (70 мс) на шаг.
- **`wave(tab, amp, delay)`** (приватная) — снимает класс `waving`, читает размеры (браузер применяет снятие), ставит `style="--wave-amp; animation-delay"` и возвращает класс: анимация начинается заново.
