# [Плавный уход со страницы (fade.rs)](/Backend/crates/branches/src/shell/fade.rs)

## Назначение
Возвращает плавный переход между страницами из TS-версии (`Gen.ts`, класс `#app.fade-out`). Islands router меняет страницу только когда она пришла с сервера, поэтому без этого модуля клик отзывался с задержкой. Здесь по клику на ссылку другой страницы `<body>` сразу получает класс `navigating`, и `#app` начинает расплываться («будто в глазах размылось»), пока идёт загрузка. Только в сборке `hydrate`.

## Ключевая функциональность
- **`fade_on_leave()`** — вызывается один раз из `hydrate` в [lib.rs](../lib.md): вешает обработчик `click` на документ (документ получает клик раньше окна, где его ловит islands router).
- **`on_click`** (приватная) — пропускает клики с модификаторами, не левой кнопкой и уже отменённые; ищет ближайший `a[href]`.
- **`leads_to_other_page(link)`** — `true`, если ссылку откроет islands router (без `target`, `download`, `rel="external"`, тот же origin) и путь отличается от текущего. Смена языка ведёт на тот же путь, поэтому здесь ничего не происходит: текст только коротко размывается в View Transition.
- **`start`** — ставит `navigating` и заводит таймер `GIVE_UP` (5 с): если страница так и не пришла, содержимое вернётся. Номер перехода в `LAST` не даёт старому таймеру снять класс у нового перехода.

## Как класс снимается
Новая страница приходит со своим `class` у `<body>` ([roots/shell.rs](../roots/shell.md)). Router переписывает атрибут, `navigating` исчезает, и `#app` проступает из размытия. Стили: [_page-transitions.scss](../../style/roots/_roots/shell/navigation/_page-transitions.md).
