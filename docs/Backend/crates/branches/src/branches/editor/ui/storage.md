# [Склад редактора (storage.rs)](/Backend/crates/branches/src/branches/editor/ui/storage.rs)

## Назначение
`Storage(title)` — склад: предметы не на поле, верхняя часть общей панели склада и каталога. Вид выбирает `Editor::stash` ([state.rs](state.md)): `StashMode::Gravity` — свободная зона с гравитацией [pile.rs](pile.md), `StashMode::List` — список в порядке поступления. Высота растёт по содержимому в обоих видах. Узел склада — цель для отпускания ([drop.rs](drop.md)); `title` — его имя для экранных дикторов, заголовка нет.

## Ключевая функциональность
- `Stored(index, piece)` (приватный) — предмет списка: блок размером с охват формы при `Up` с `PieceArt` (открытая картинка сумки); нажатие начинает перетаскивание с `Origin::Storage`.
