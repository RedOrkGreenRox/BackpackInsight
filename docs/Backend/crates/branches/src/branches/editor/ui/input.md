# [Управление перетаскиванием (input.rs)](/Backend/crates/branches/src/branches/editor/ui/input.rs)

## Назначение
Управление перетаскиванием (решение Ивана): ЛКМ или палец — взять и тащить; ПКМ, СКМ, пробел или `R` (и `К` в русской раскладке) — поворот; второй палец на телефоне — поворот; `Esc` — вернуть на место.

## Ключевая функциональность
- `start(editor, origin, piece, ev)` — по ЛКМ запоминает `Drag` (поворот предмета с поля, точку захвата из [dom.rs](dom.md), для каталога — центр) и сбрасывает `hover`.
- `listen(editor)` — слушатели окна, снимаются в `on_cleanup`:
  - `pointermove` — двигает указатель; после порога меряет клетку поля и снимает предмет ([drop.rs](drop.md) `lift`);
  - `pointerup` / `pointercancel` — `finish` (отмена при `pointercancel`);
  - `pointerdown` чужим касанием и `mousedown` не ЛКМ (при зажатой ЛКМ браузер шлёт их как `mousedown`) — поворот;
  - `contextmenu` — без меню, пока что-то в руке; `keydown` — поворот и `Esc`.
- Приватные `rotate`, `end`.
