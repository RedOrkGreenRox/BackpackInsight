# [Склад с гравитацией (pile.rs)](/Backend/crates/branches/src/branches/editor/ui/pile.rs)

## Назначение
`PileArea()` — свободная зона склада: тела `Pile` ([model/pile.rs](../model/pile.md)) падают и ложатся друг на друга. Позиции — в клетках склада, CSS переводит их в размеры (`var(--cell)`).

## Ключевая функциональность
- `STASH_SCALE` = 0.7 — клетка склада от клетки поля (как `--cell` в [_panels.scss](../../../../style/branches/editor/_panels.md)); `DT` — шаг физики 1/60 с.
- `Effect` при каждом изменении набора или склада: `Pile::reconcile` со списком склада. Подсказка `Editor::spawn` (указатель и точка захвата при отпускании над складом, [drop.rs](drop.md)) переводится `spawn_cells` в клетки — новый предмет появляется там, где его отпустили, и падает. Затем `animate`.
- `animate` / `frame` — кадры `request_animation_frame` с `Pile::step`, пока что-то падает; флаг `running` не даёт запустить два цикла. Изменение размера окна тоже будит цикл (ширина склада могла измениться).
- `stash_cell` (клетка склада по ширине поля), `width` (ширина зоны в клетках, до измерения — 8).
- Высота зоны — `Pile::rows`; `PileBody(index, piece)` (приватный) — тело: `left`/`bottom` из позиции, нажатие начинает перетаскивание с `Origin::Storage(index)` (номер тела = номер на складе).
