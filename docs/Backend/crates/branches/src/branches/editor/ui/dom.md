# [Обращения редактора к странице (dom.rs)](/Backend/crates/branches/src/branches/editor/ui/dom.rs)

## Назначение
Обращения к странице: размеры, захват указателя, адрес, настройки зрителя. Работают только в браузере (`hydrate`), на сервере это заглушки.

## Ключевая функциональность
- `rect(node)` — `getBoundingClientRect` узла в `Rect` ([state.rs](state.md)).
- `grab(ev)` — где внутри элемента под событием нажали, доли 0..1 (по умолчанию центр).
- `capture(ev)` — захват указателя элементом под событием (`setPointerCapture`) для ручек размера ([grip.rs](grip.md)).
- `pref(key)` / `set_pref(key, value)` — настройка в `localStorage`; пустое значение её убирает, недоступное хранилище не мешает работе.
- `replace_query(pairs)` — ставит или убирает параметры адреса через `history.replaceState`, только если адрес изменился.
- `json_data_url(json)` — `data:`-ссылка с процентным кодированием для кнопки «Скачать».
