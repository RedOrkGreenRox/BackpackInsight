# [Поле рюкзака (field.rs)](/Backend/crates/branches/src/branches/editor/ui/field.rs)

## Назначение
`Field(label, info, hint, resize)` — поле 9 × 6, по центру страницы, в рамке `.ed-frame` из игры (сетка клеток нарисована на её фоне; в режиме сумок рамка получает `.ed-frame-bags` и становится оранжевой): слой сумок, слой предметов (в режиме сумок полупрозрачный и не берётся, класс `ed-ghosted`) и слой отметок ([marks.rs](marks.md)).

## Ключевая функциональность
- Сумки и предметы — через `For` с ключом «номер + `Placed`».
- `FieldPiece(placed, origin)` (приватный) — блок `.ed-piece` по `box_style`; нажатие начинает перетаскивание ([input.rs](input.md)), наведение ставит `hover` для звёзд.
- В правом верхнем углу рамки — кнопка «i» (`info`), она показывает и прячет подсказку по управлению (`hint`); заголовков и подписей у поля нет.
- Нижний край рамки — ручка размера поля `Grip` ([grip.rs](grip.md)): меняет `Editor::field_cell`, сдвиг указателя делится на высоту рамки `FRAME_ROWS` = 6.52 клетки.
