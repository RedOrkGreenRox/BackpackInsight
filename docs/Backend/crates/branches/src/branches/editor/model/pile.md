# [Склад с гравитацией: модель (pile.rs)](/Backend/crates/branches/src/branches/editor/model/pile.rs)

## Назначение
`Pile` — тела склада с гравитацией; `Body { piece, x, y, vy }` — предмет: левый нижний угол охвата формы в клетках склада (`x` от левой стенки, `y` вверх от дна) и скорость падения. Без браузера: кадры даёт [ui/pile.rs](../ui/pile.md).

## Ключевая функциональность
- Упрощение по сравнению с игрой: предметы не поворачиваются и не кувыркаются — лежат формой `Up`, падают вертикально и останавливаются на дне или на клетках других предметов (касания — [contact.rs](contact.md)).
- `reconcile(kit, storage, spawn, width)` — тела в порядке `Board::storage`: прежние остаются на месте, новые появляются в `spawn` или, без подсказки, над кучей слева направо; появившиеся внутри другого предмета поднимаются над ним.
- `step(kit, width, dt)` — шаг снизу вверх: ширина склада ограничивает `x`, пересечения выталкиваются вверх, затем падение с ускорением `GRAVITY` (не быстрее `MAX_SPEED`) до опоры. Возвращает `true`, пока что-то падает.
- `rows(kit)` — высота склада: куча плюс строка, не ниже `MIN_ROWS`.
- `top_of` (приватная) — верх самого высокого тела.
