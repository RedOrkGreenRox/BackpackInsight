# [Предмет на поле (placed.rs)](/Backend/crates/branches/src/branches/editor/model/placed.rs)

## Назначение
`Placed { piece, pos, orient }` — предмет или сумка на поле: номер в `Kit`, опорная клетка, поворот.

## Ключевая функциональность
- `cells(kit)` — занятые клетки ([cell.rs](cell.md) `place`).
- `carried(from, to)` — где окажется предмет из сумки `from`, когда сумку переставили и повернули в `to`: смещение от сумки поворачивается на `to.orient.since(from.orient)`, к повороту предмета прибавляется тот же поворот.

## Связи
- Используется в [board.rs](board.md) и при перетаскивании ([ui/drop.rs](../ui/drop.md)).
