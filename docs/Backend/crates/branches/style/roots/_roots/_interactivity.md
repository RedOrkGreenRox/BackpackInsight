# [Интерактивность (_interactivity.scss)](/Backend/crates/branches/style/roots/_roots/_interactivity.scss)

## Назначение
Файл управляет поведением интерфейса в плане взаимодействия пользователя с контентом: запрет на выделение текста, перетаскивание изображений и специфические режимы курсора.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/roots/_roots/_interactivity.scss](/docs/Frontend/ground/roots/_roots/_interactivity.md).
Общие стили каркаса: подключаются в [site.scss](../../site.md) глобально.

## Содержимое
- Классы и id: `.h1`, `.h2`, `.upload-area`.
