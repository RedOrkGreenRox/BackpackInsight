# [Сброс стилей (_reset.scss)](/Backend/crates/branches/style/roots/_roots/_reset.scss)

## Назначение
Базовый файл сброса стилей (Reset), обеспечивающий единообразное отображение приложения в различных браузерах и задающий фундаментальные настройки типографики.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/roots/_roots/_reset.scss](/docs/Frontend/ground/roots/_roots/_reset.md).
Общие стили каркаса: подключаются в [site.scss](../../site.md) глобально.

## Содержимое
- Только правила для элементов и медиазапросы, без собственных классов.
