# [Планшетная вёрстка библиотеки (_tablet.scss)](/Backend/crates/branches/style/branches/items/_items/responsive/_tablet.scss)

## Назначение
Коррекция элементов библиотеки предметов для экранов шириной до 768px.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/items/_items/responsive/_tablet.scss](/docs/Frontend/ground/branches/items/_items/responsive/_tablet.md).
В [site.scss](../../../../site.md) подключается через `meta.load-css` внутри `main[data-branch="ItemsBranch"]` и `main[data-branch="EditorBranch"]`, поэтому действует только на этих страницах.

## Содержимое
- Классы и id: `.filter-controls`, `.advanced-filters-panel`, `.filter-label`, `.filter-chip`, `.filter-icon`, `.text-icon`, `#filterHeroes`, `.filter-multiselect`, `.search-container`, `.search-input`, `.main-title`, `.wiki-subtitle`.
