# [Раскладка редактора (_layout.scss)](/Backend/crates/branches/style/branches/editor/_layout.scss)

## Назначение
Раскладка редактора сверху вниз на любом экране: панель кнопок и поле ровно по центру, под ними во всю ширину одна панель склада и каталога ([_panels.scss](_panels.md)).

## Ключевая функциональность
- `.ed-editor`: `--field-cell` (клетка поля, `clamp(2.25rem, min((100vw − отступы) / 9.62, (50vh − 4rem) / 6.52), 4.25rem)` — рамка поля 9.62 × 6.52 клетки помещается в ширину и в верхнюю половину окна) и `--cell`; ручка поля задаёт `--field-cell` инлайн.
- `.ed-board`, `.ed-heading`, `.ed-hint`, `.ed-button` (`.ed-on` — включённый режим), `.ed-dragging` (без выделения текста и прокрутки пальцем).
