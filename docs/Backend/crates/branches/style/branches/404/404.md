# [Стили страницы 404 (404.scss)](/Backend/crates/branches/style/branches/404/404.scss)

## Назначение
Главный агрегатор стилей для страницы ошибки. Координирует сборку всех визуальных компонентов: от полноэкранного фона до типографики.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/404/404.scss](/docs/Frontend/ground/branches/404/404.md).
В [site.scss](../../site.md) подключается глобально: все селекторы с суффиксом `-404` или под `body.error-404`.
