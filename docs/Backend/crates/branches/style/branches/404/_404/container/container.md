## Назначение
Рендерер центрального блока контента на странице 404. Определяет структуру для вставки заголовка и кнопок.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/404/_404/container/container.scss](/docs/Frontend/ground/branches/404/_404/container/container.md).
В [site.scss](../../../../site.md) подключается глобально: все селекторы с суффиксом `-404` или под `body.error-404`.

- Классы и id: `.container-404`.
