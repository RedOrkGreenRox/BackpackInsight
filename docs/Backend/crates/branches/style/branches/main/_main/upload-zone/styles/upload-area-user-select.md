## Назначение
Разрешает выделение и копирование текста внутри зоны загрузки, переопределяя глобальные запреты.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/main/_main/upload-zone/styles/upload-area-user-select.scss](/docs/Frontend/ground/branches/main/_main/upload-zone/styles/upload-area-user-select.md).
В [site.scss](../../../../../site.md) подключается через `meta.load-css` внутри `main[data-branch="MainBranch"]`, поэтому действует только на главной.
