# [branches/shell/mod.rs](/RBackend/crates/branches/src/shell/mod.rs)

## Назначение
Острова общего каркаса сайта: боковая панель с меню и параллакс фона, а в браузере ещё докачка WASM ленивых островов. В отличие от [roots](../roots/mod.md), модуль компилируется в обе сборки (`ssr` и `hydrate`): сервер рендерит острова в HTML, WASM их оживляет. Остальной каркас (документ, фон, выбор ветки) рисует сервер в [roots/shell.rs](../roots/shell.md).

## Ключевая функциональность
Модуль только объявляет подмодули и реэкспортирует их публичные типы:

| Имя | Откуда | Роль |
| :--- | :--- | :--- |
| `SidebarManager`, `NavTab`, `SidebarLabels` | [sidebar.rs](sidebar.md) | кнопка меню, выезжающая панель, переключатель языка |
| `ParallaxManager` | [parallax.rs](parallax.md) | смещение фона за курсором |
| `prefetch_lazy_islands` | [prefetch.rs](prefetch.md) | только `hydrate`: докачка WASM ленивых островов в простое |

Имена с суффиксом `Manager` повторяют дендритную схему TS-версии, где интерактивные части страницы — менеджеры.

## Связи
- Подключается в [lib.rs](../lib.md) без условий компиляции; `prefetch` — только с фичей `hydrate`.
- Использование: `App` в [roots/shell.rs](../roots/shell.md) и `sidebar` в [roots/chrome.rs](../roots/chrome.md).
