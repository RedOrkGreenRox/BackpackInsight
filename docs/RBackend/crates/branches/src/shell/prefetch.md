# [Докачка ленивых островов (prefetch.rs)](/RBackend/crates/branches/src/shell/prefetch.rs)

## Назначение
`prefetch_lazy_islands` — браузерная часть ленивых островов. Докачивает в HTTP-кэш WASM тех ленивых островов, которых нет на текущей странице, уже после её загрузки. Тогда при переходе (например, Главная → Каталог) остров оживает из кэша, а не ждёт сеть. Компилируется только с фичей `hydrate`.

## Ключевая функциональность
- **`prefetch_lazy_islands()`** — вызывается из `hydrate()` в [lib.rs](../lib.md) после `hydrate_islands`:
  - если документ уже загружен (`readyState == "complete"`), сразу планирует докачку;
  - иначе ждёт событие `load` окна.
- **`when_idle`** — откладывает докачку до простоя браузера через `requestIdleCallback`. В браузерах без него (Safari) делает это через `setTimeout` на 1 с.
- **`fetch_all`** — находит `link[rel="preload"][type="application/wasm"][media="not all"]` (такие ссылки ставит сервер, [roots/lazy.rs](../roots/lazy.md)) и для каждой делает `fetch(href)`. Ответ дочитывается (`arrayBuffer`): в кэше остаётся только полностью прочитанный ответ. Сервер отдаёт `/pkg` с `Cache-Control: public, max-age=3600` ([roots/runner.rs](../roots/runner.md)).

Ошибки сети и отсутствие API не ломают страницу: все результаты игнорируются, докачка лишь ускоряет следующий переход.
