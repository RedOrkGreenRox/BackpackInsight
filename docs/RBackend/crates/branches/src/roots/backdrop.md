# [branches/roots/backdrop.rs](/RBackend/crates/branches/src/roots/backdrop.rs)

## Назначение
Выбор фоновой картинки страницы. Перенос `Shell.setRandomBackground` и 404-`BackgroundManager` из TS-версии с одним отличием: при переходах внутри сайта фон не меняется. Иначе islands router увидел бы новый `src` у `#bgImg` и перерисовал бы фон при каждом клике или смене языка.

## Ключевая функциональность
- **`Backdrop { avif, webp }`** — пара путей к картинке: AVIF для `<source>` и запасной WebP для `<img>` в [shell.rs](shell.md).
- **`Backdrop::choose(ctx, not_found)`**:
  - **Обычная страница.** Номер локации `01`–`20` → `/images/area/{avif,webp}/areaNN.*`. При переходе через islands router (`ctx.navigation`) номер берётся из cookie `bi_bg`, при первой загрузке он случайный, как в TS-версии.
  - **404.** Редкость `00`–`04` → `/images/404/{avif,webp}/NN.*` с весами TS-версии: 80 % / 15 % / 4 % / 0,9 % / 0,1 %. Cookie `bi_bg404` переиспользуется, только если это переход с `?lang=`, то есть смена языка на той же странице 404. Новый заход на 404 снова тянет случайную редкость.
  - Выбранный номер всегда записывается обратно в cookie через `ctx.remember` (сессионная cookie, см. [ctx.rs](ctx.md)).
- **`reuse(ctx, cookie, keep, valid)`** (приватная) — значение cookie, если его разрешено переиспользовать (`keep`) и оно прошло проверку `valid`. Битое или чужое значение игнорируется, и фон выбирается заново.
- **`random_rarity()`** (приватная) — редкость фона 404 по порогам `RARITY_THRESHOLDS` (в десятых долях процента, от большего порога к меньшему).
- **`random()`** (приватная) — случайное `u64` без внешних зависимостей: `RandomState` каждый раз засевается операционной системой.

## Тесты
- `rarity_codes_are_known` — 200 бросков дают только коды `00`–`04`; пороги строго убывают.
