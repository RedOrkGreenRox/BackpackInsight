# [Словари интерфейса (i18n.rs)](/RBackend/crates/branches/src/roots/i18n.rs)

## Назначение
`Dict` — словари интерфейса. Источник общий с TS-фронтендом: [en.json](/docs/Frontend/static/lang/en.md) и [ru.json](/docs/Frontend/static/lang/ru.md) в `Frontend/Web/static/lang/`. Подстановки совместимы с [i18n.ts](/docs/Frontend/ground/localization/i18n.md).

## Ключевая функциональность
- **`struct Dict`** — `Arc<HashMap<Lang, HashMap<String, String>>>`: клонирование стоит одного счётчика ссылок, поэтому словарь кладётся в контекст Leptos и копируется в каждый `BranchCtx`.
- **`Dict::load(project_root)`** — для каждого языка из `Lang::ALL` читает `{project_root}/Frontend/Web/static/lang/{code}.json` как плоский JSON-объект строк. Ошибка чтения или разбора возвращается строкой с путём файла и останавливает запуск сервера (`BranchRunner::serve`).
- **`t(lang, key)`** — перевод; при отсутствии ключа — английский вариант, при отсутствии и его — сам ключ. Пустой строки или паники не бывает.
- **`tf(lang, key, args)`** — перевод с подстановкой: каждая пара `(name, value)` заменяет и `{{name}}`, и `{name}` (позиционные `{0}` задаются как `("0", value)`).
- **`lookup(lang, key)`** (приватная) — поиск без запасных вариантов.

Счётчик «Найдено: {0}» в острове каталога подставляется не здесь, а в самом острове: в браузер уходит только шаблон строки (`ItemsLabels`, см. [model.rs](../model.md)).

## Тесты
- `falls_back_and_substitutes` — запасной английский, обе формы подстановки, отсутствующий ключ.

## Связи
- Используется через `BranchCtx::t`/`tf` ([ctx.rs](ctx.md)); загружается в [runner.rs](runner.md).
