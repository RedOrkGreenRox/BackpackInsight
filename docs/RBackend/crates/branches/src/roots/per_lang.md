# [branches/roots/per_lang.rs](/RBackend/crates/branches/src/roots/per_lang.rs)

## Назначение
Помощник для островов, чьи пропсы зависят от языка. Islands router Leptos при переходе обновляет серверный HTML, но острова (`<leptos-island>`) не трогает, чтобы не потерять их состояние. Поэтому после смены языка остров остался бы со старыми подписями.

## Ключевая функциональность
- **`per_lang(lang, view)`** → `Either<V, V>`: английский язык кладёт разметку в `Left`, русский в `Right`. В режиме `islands-router` Leptos помечает ветки `Either` комментариями-маркерами, и router, увидев другую ветку, заменяет её содержимое целиком вместе с островом.
- Тип разметки один и тот же, меняется только ветка, поэтому обёртка ничего не стоит при рендере.
- При добавлении третьего языка в `Lang` ([model.rs](../model.md)) компилятор потребует расширить `match`: тогда `Either` нужно заменить на `EitherOf3` или аналог.
