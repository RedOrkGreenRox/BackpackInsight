# [branches/roots/request.rs](/RBackend/crates/branches/src/roots/request.rs)

## Назначение
Разбор сырого запроса без зависимостей от Leptos: query-строка, cookie и выбор языка. Чистые функции, поэтому покрыты юнит-тестами.

## Ключевая функциональность
- **`LANG_COOKIE`** = `"lang"` — имя cookie с выбранным языком; его же пишет `BranchCtx::current` ([ctx.rs](ctx.md)).
- **`parse_query(query)`** — пары `ключ=значение` из query в формате `application/x-www-form-urlencoded`. Пустые пары пропускаются, параметр без `=` получает пустое значение, ключ и значение декодируются `form_decode`.
- **`resolve_lang(query, headers)`** — язык запроса по приоритету `?lang=` → cookie `lang` → `Accept-Language` (первый язык из списка, который знает `Lang::parse`) → английский. Второй элемент кортежа — `true` только для `?lang=`: такой выбор нужно запомнить в cookie.
- **`form_decode(input)`** (приватная) — `+` → пробел, `%XX` → байт; некорректная последовательность (`%zz`, обрезанный `%`) остаётся как есть. Байты собираются в UTF-8 с заменой битых символов (`from_utf8_lossy`), поэтому кириллица в `?q=` декодируется корректно.

## Тесты
- `decodes_form_query` — кириллица в процентах, `+`, битый `%zz`, параметр без значения.
- `language_priority_is_query_cookie_header` — порядок: заголовок < cookie < query, флаг «запомнить» только у query.

## Связи
- Единственный потребитель: [ctx.rs](ctx.md).
- Разбор кодов языков: `Lang::parse` в [model.rs](../model.md).
- Обратная операция (кодирование ссылок каталога): [items/url.rs](../branches/items/url.md).
