# [Проверка конца прокрутки (scroll.rs)](/RBackend/crates/branches/src/branches/items/scroll.rs)

## Назначение
Проверка «страница докручена почти до конца» для бесконечной прокрутки каталога. Вынесена из острова, чтобы `ItemsManager` не знал про размеры окна и `web-sys`.

## Ключевая функциональность
- **`THRESHOLD_PX`** = 800 (только `hydrate`) — сколько пикселей до низа документа считается «почти у конца». Запас нужен, чтобы следующая порция успела прийти раньше, чем пользователь упрётся в край.
- **`near_bottom()`** — `innerHeight + scrollY ≥ scrollHeight − THRESHOLD_PX`. Отсутствующие значения считаются нулём. На сервере (без `hydrate`) всегда `false`.

## Связи
- Единственный потребитель: обработчик прокрутки в [manager.rs](manager.md).
- Модуль ветки: [items/mod.rs](mod.md) (подмодуль приватный).
