# [Ссылки каталога (url.rs)](/RBackend/crates/branches/src/branches/items/url.rs)

## Назначение
Ссылки каталога. Чистые функции без зависимостей, работают одинаково на сервере и в WASM — поэтому адрес после `replaceState` совпадает с тем, что понимает `ItemsBranch`.

## Ключевая функциональность
- **`items_href(query, page)`** — `/items` с параметрами: `q` (обрезанный по краям и закодированный), только если непустой; `page`, только если больше нуля. Без параметров — просто `/items`.
- **`encode(value)`** — процентное кодирование значения query-параметра по байтам UTF-8: без изменений остаются только `A-Z a-z 0-9 - _ . ~`, всё прочее (включая пробел, `&`, кириллицу) → `%XX` в верхнем регистре. Обратное преобразование на сервере — `form_decode` в [roots/request.rs](../../roots/request.md).

## Тесты
- `builds_catalog_links` — пустой запрос, кириллица с пробелами по краям и `page=2`, экранирование `&`.

## Связи
- Используется в [manager.rs](manager.md) (`replace_url` после поиска).
