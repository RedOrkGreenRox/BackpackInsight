# [Снятие и укладка предмета (drop.rs)](/RBackend/crates/branches/src/branches/editor/ui/drop.rs)

## Назначение
Снять предмет в начале перетаскивания и положить в конце. Куда кладём, решает место отпускания.

## Ключевая функциональность
- `lift(editor, drag)` — по `Origin` берёт предмет из каталога, со склада (`take_stored`), с поля (`lift_item`) или сумку с её предметами (`lift_bag`).
- `finish(editor, drag, cancel)`:
  - над полем и `Board::fits` — `drop_bag` (перенесённые предметы через `Placed::carried`) или `drop_item`;
  - над складом — на склад, у сумки вместе с её предметами (`store`); на складе с гравитацией (`StashMode::Gravity`) запоминает в `Editor::spawn` указатель и точку захвата, чтобы предмет появился там, где его отпустили ([pile.rs](pile.md));
  - над каталогом — предмет убирается, предметы из сумки уходят на склад;
  - иначе или при отмене — `give_back`: туда, откуда взяли; новый из каталога исчезает.
