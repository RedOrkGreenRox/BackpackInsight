# [Каталог редактора (palette.rs)](/RBackend/crates/branches/src/branches/editor/ui/palette.rs)

## Назначение
`Palette(labels)` — каталог вместо магазина: поиск, вид (всё / сумки / предметы), редкость, порядок; герой берётся из билда (`Editor::hero`). Карточки показываются по `PAGE` = 60 с кнопкой «Показать ещё». Узел каталога — цель «убрать предмет». Каталог — нижняя часть общей панели со складом.

## Ключевая функциональность
- `Filter` в сигнале; любое изменение сбрасывает счётчик показанных ([model/filter.rs](../model/filter.md)).
- `Card(piece)` (приватный) — картинка, вписанная в квадрат по большей стороне формы (`--w`, `--h`), имя цветом редкости; нажатие начинает перетаскивание с `Origin::Catalog`. На телефоне список прокручивается пальцем вертикально, предмет берётся движением вбок (`touch-action: pan-y`).
- Под списком — ручка `Grip` ([grip.rs](grip.md)): высота списка `Editor::catalog_height` (`max-height`); до первого перетаскивания берётся высота списка на странице.
- `kind_options`, `sort_options` (приватные) — варианты вида и порядка на языке страницы.
