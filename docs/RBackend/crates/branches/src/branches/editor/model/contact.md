# [Касания тел склада (contact.rs)](/RBackend/crates/branches/src/branches/editor/model/contact.rs)

## Назначение
Геометрия склада с гравитацией ([pile.rs](pile.md)): клетки формы — единичные квадраты; соседние по стороне не пересекаются (допуск `EPS`).

## Ключевая функциональность
- `shape(kit, piece)` — клетки формы `Up` со сдвигом к `(0, 0)`; пустая форма — одна клетка.
- `width_of(kit, piece)` — ширина формы.
- `free_y(body, cells, others)` — наименьший `y` не ниже текущего, при котором тело ни с кем не пересекается (подъём шагами до 64 раз).
- `floor(body, cells, others)` — до какого `y` тело может упасть: дно или верх клеток под ним.
