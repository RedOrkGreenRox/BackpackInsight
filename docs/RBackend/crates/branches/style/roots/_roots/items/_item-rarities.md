# [Цвета редкостей карточек (_item-rarities.scss)](/RBackend/crates/branches/style/roots/_roots/items/_item-rarities.scss)

## Назначение
Связующий файл, который назначает цвета из переменных конкретным CSS-классам редкостей.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/roots/_roots/items/_item-rarities.scss](/docs/Frontend/ground/roots/_roots/items/_item-rarities.md).
Общие стили каркаса: подключаются в [site.scss](../../../site.md) глобально.

## Содержимое
- Классы и id: `.rarity-common`, `.rarity-rare`, `.rarity-epic`, `.rarity-legendary`, `.rarity-mythic`, `.rarity-unique`, `.rarity-relic`, `.rarity-boon`, `.rarity-special`.
- CSS-переменные: `--rarity-glow-color`.
