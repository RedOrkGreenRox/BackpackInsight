# [CSS-переменные (_vars.scss)](/RBackend/crates/branches/style/roots/_roots/_vars.scss)

## Назначение
Глобальный конфигурационный файл CSS-переменных (CSS Custom Properties), определяющий цветовую схему, эффекты свечения и базовые метрики типографики для всего приложения.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/roots/_roots/_vars.scss](/docs/Frontend/ground/roots/_roots/_vars.md).
Общие стили каркаса: подключаются в [site.scss](../../site.md) глобально.

## Содержимое
- CSS-переменные: `--azure`, `--azure-glow-high`, `--azure-glow-low`, `--azure-raw`, `--border`, `--text-default-color`, `--text-header-color`, `--wiki-stats-text-size`.
