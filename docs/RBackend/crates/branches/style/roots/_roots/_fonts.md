# [style/roots/_roots/_fonts.scss](/RBackend/crates/branches/style/roots/_roots/_fonts.scss)

## Назначение
Этот файл отвечает за загрузку и оптимизацию шрифтов, используемых в проекте. Он гарантирует правильное отображение текста на разных языках и начертаниях.

Перенесён из TS-версии ([ground/roots/_roots/_fonts.scss](/docs/Frontend/ground/roots/_roots/_fonts.md)). Единственное отличие от TS-версии: пути шрифтов `/static/fonts/…` заменены на `/fonts/…`, потому что сервер `branches` раздаёт шрифты по `/fonts`.
Общие стили каркаса: подключаются в [site.scss](../../site.md) глобально.

## Содержимое
- Только правила для элементов и медиазапросы, без собственных классов.
