# [style/branches/items/_items/filters/_filter-controls.scss](/RBackend/crates/branches/style/branches/items/_items/filters/_filter-controls.scss)

## Назначение
Верхнеуровневый контейнер для всей системы фильтров на странице Вики. Задает максимальную ширину и отступы блока.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/items/_items/filters/_filter-controls.scss](/docs/Frontend/ground/branches/items/_items/filters/_filter-controls.md).
В [site.scss](../../../../site.md) подключается через `meta.load-css` внутри `main[data-branch="ItemsBranch"]` и `main[data-branch="EditorBranch"]`, поэтому действует только на этих страницах.

## Содержимое
- Классы и id: `.filter-controls`.
