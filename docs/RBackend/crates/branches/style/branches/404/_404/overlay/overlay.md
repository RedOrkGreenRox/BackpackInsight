# [Виньетка страницы 404 (overlay.scss)](/RBackend/crates/branches/style/branches/404/_404/overlay/overlay.scss)

## Назначение
Стилизация виньетирующего слоя, который создает акцент на центральном блоке текста.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/404/_404/overlay/overlay.scss](/docs/Frontend/ground/branches/404/_404/overlay/overlay.md).
В [site.scss](../../../../site.md) подключается глобально: все селекторы с суффиксом `-404` или под `body.error-404`.

## Содержимое
- Классы и id: `.overlay-404`.
