# [Фон страницы 404 (background.scss)](/RBackend/crates/branches/style/branches/404/_404/background/background.scss)

## Назначение
Класс `BackgroundManager` управляет системой «редкостных» фонов для страницы 404, имитируя механику выпадения предметов в игре Backpack Brawl.

Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/404/_404/background/background.scss](/docs/Frontend/ground/branches/404/_404/background/background.md).
В [site.scss](../../../../site.md) подключается глобально: все селекторы с суффиксом `-404` или под `body.error-404`.

## Содержимое
- Классы и id: `.bg-404`.
