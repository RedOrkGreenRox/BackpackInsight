Перенесён из TS-версии без изменений; подробное описание правил — в доке оригинала [ground/branches/main/_main/container/container.scss](/docs/Frontend/ground/branches/main/_main/container/container.md).
В [site.scss](../../../../site.md) подключается через `meta.load-css` внутри `main[data-branch="MainBranch"]`, поэтому действует только на главной.
