# [Стили поля редактора (_field.scss)](/RBackend/crates/branches/style/branches/editor/_field.scss)

## Назначение
Поле 9 × 6 и его слои: `.ed-field`, `.ed-grid`, `.ed-cell`, `.ed-layer`, `.ed-piece`, `.ed-art` (картинка по центру, поворот — инлайн), `.ed-ghosted` (режим сумок), отметки `.ed-mark-fits` / `.ed-mark-blocked` / `.ed-mark-star` (★) и `.ed-ghost` (предмет под указателем, `position: fixed`).
