# [art/kit.rs](/RBackend/crates/art/src/kit.rs)

## Назначение
Индекс картинок распакованного ContentKit: нормализованное имя файла → пути. Папка героя в ключ не входит, потому что от версии к версии предметы переезжают между папками, а имя файла остаётся.

## API
- **`KitIndex::scan(kit, roots)`** — рекурсивно обходит существующие папки `roots`, собирает `.png` (регистр расширения не важен). Ошибка, если не найдено ни одной папки.
- **`find(stem)`** — все файлы с таким именем; **`one(stem)`** — ровно один, иначе ошибка «нет файла» или «неоднозначно».
- **`paths()`** — все файлы (для поиска лишних картинок в [check.rs](check.md)).
- **`stem_key(stem)`** — только ASCII-буквы и цифры в нижнем регистре: `Bosun's Monocular` = `bosuns monocular`.

## Тесты
`stem_key_ignores_case_and_punctuation`.

## Связи
