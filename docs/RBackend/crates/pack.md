# pack — runtime-чтение FlatBuffer packs

`pack` — маленький runtime crate для чтения сгенерированных FlatBuffer packs.

Эта контрольная точка подключает первый настоящий pack:

```text
RBackend/generated/catalog_summary.fb
```

Структура:

```text
pack/src/generated/catalog_generated.rs  generated by flatc from catalog.fbs
pack/src/catalog.rs                      безопасная обёртка чтения catalog summary
pack/src/lib.rs                          re-export
```

`pack` не строит pack-и. Он только читает и проверяет их.

Сборкой занимается `builder`.
