# [core/lib.rs](/RBackend/crates/core/src/lib.rs)

## Назначение
Корень crate `rbackend_core` — общие доменные правила BackpackInsight: `SlugService`, `ItemIconService`, `LevelService`, `AreaService`, `HeroService` и т.д. Публичные имена сохраняют язык текущей архитектуры.

## Ключевая функциональность
- Агрегирует модули `catalog` и `profile`.
