# [Идентификаторы каталога (ids.rs)](/RBackend/crates/core/src/catalog/ids.rs)

## Назначение
Компактные типизированные идентификаторы строк каталога, чтобы не путать индексы предметов, героев и строк.

## Типы
| Тип | Хранение | `Display` |
| :--- | :--- | :--- |
| `ItemId` | `u32` — номер строки в [CatalogColumns](columns.md) | `item#N` |
| `HeroId` | `u16` | `hero#N` |
| `StringId` | `u32` — индекс в [StringPool](strings.md) | `str#N` |

У каждого: `const fn new(raw)`, `raw()` (исходное число) и `index()` (то же как `usize` для индексации векторов). Все типы `Copy`, сравнимы и хешируемы.

`HeroId` пока нигде за пределами модуля не используется.
