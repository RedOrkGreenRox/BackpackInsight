# [Пул строк (strings.rs)](/RBackend/crates/core/src/catalog/strings.rs)

## Назначение
`StringPool` — минимальный детерминированный интернер строк: одинаковые строки получают один и тот же `StringId` ([ids](ids.md)), id выдаются по порядку вставки.

## API
- `new()` — пустой пул.
- `intern(value)` — возвращает существующий id или добавляет строку с id = текущей длине пула.
- `get(id)` — строка по id или `None`.
- `len()` / `is_empty()` — число уникальных строк.
- `iter()` — пары `(StringId, &str)` в порядке вставки.

Внутри: вектор значений и `BTreeMap` для обратного поиска. Сравнение чувствительно к регистру.
