# [Общие типы профиля (types.rs)](/RBackend/crates/core/src/profile/types.rs)

## Назначение
Общие маленькие value-типы профиля, которые используют несколько правил сразу.

## Типы
- `Xp(u64)` — опыт (суммарный или текущий внутри уровня); `Default` = 0, `Display` — число.
- `PlayerLevel(u64)` — уровень игрока; `Display` — число.
- `PlayerArea(u8)` — номер игровой области. `code()` возвращает двузначный код (`"01"` … `"20"`), который совпадает с именами фоновых картинок областей на фронтенде; `Display` выводит тот же код.
- `LevelProgress` — результат расчёта уровня: `level`, `current` (опыт внутри уровня) и `need` (сколько нужно на этот уровень).

## Связи
- `PlayerArea` вычисляет [area](area.md); `LevelProgress` — [level](level.md); `Xp` также использует [items/xp](items/xp.md).
