# [Уровень героя (level.rs)](/RBackend/crates/core/src/profile/heroes/level.rs)

## Назначение
`HeroLevelService` — уровень героя с учётом престижа и опыт, нужный до следующего уровня.

## Данные
`HERO_LEVELING_EXP` — пары (уровень, опыт) для уровней 1–20: 0, 100, 200, 350, 500, 650, 800, 1000, 1200, 1400, 1650, 1900, 2200, 2500, 2850, 3200, 3600, 4050, 4500, 5000.

## API
- `from_raw_level(raw_level)` — уровень в профиле хранится с нуля, поэтому к нему прибавляется 1. Если результат больше 20, вычитается 20 и возвращается флаг престижа: сырой 25 → уровень 6 с престижем.
- `exp_need(level)` — опыт для перехода на следующий уровень: для следующего уровня до 20 — значение из таблицы (`hero_level_exp`), дальше — `1000 + 100 × (следующий − 21)`, не больше 3000.

## Связи
Собирается в `HeroService` ([heroes/mod](mod.md)).
