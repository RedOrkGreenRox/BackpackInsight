# [core/profile/level.rs](/RBackend/crates/core/src/profile/level.rs)

## Назначение
`LevelService` считает уровень игрока по суммарному опыту.

## Данные
- `PROFILE_EXP_NEED` — 100 значений: опыт, нужный для перехода с уровня N на N+1 (от 40 и 280 на первых уровнях до 100000 в конце таблицы).
- `POST_TABLE_LEVEL_XP` — 100000: стоимость каждого уровня после конца таблицы.

## API
- `from_total_xp(total_xp)` — идёт по таблице, вычитая стоимость уровней. Возвращает `LevelProgress` ([types](types.md)): уровень (начиная с 1), опыт внутри текущего уровня и стоимость текущего уровня. После таблицы оставшийся опыт делится на шаги по 100000.
- `exp_table()` — ссылка на таблицу.

## Пример
0 опыта → уровень 1, `0 / 40`; 40 опыта → уровень 2, `0 / 280`.

## Связи
- Используется при сборке профиля в [api/profile/view](../../../api/src/profile/view.md).
