# [core/profile/area.rs](/RBackend/crates/core/src/profile/area.rs)

## Назначение
`AreaService` переводит сумму трофеев игрока в номер игровой области (арены).

## Данные
`PROFILE_AREAS` — 20 порогов трофеев: `0, 5, 50, 100, 200, 300, 400, 500, 700, 1000, 1600, 2300, 3500, 4800, 6500, 8500, 12000, 16000, 22000, 30000`.

## API
- `from_trophies(trophy, bonus_trophy)` — складывает обычные и бонусные трофеи (с насыщением) и возвращает `PlayerArea` с индексом первого порога, который ещё не достигнут. Сумма 0–4 → область `01`, 5–49 → `02`, …, 22000–29999 → `19`, от 30000 — `20`.
- `area_table()` — ссылка на таблицу порогов.

## Связи
- Используется в [score](score.md); тип результата — [types](types.md).
