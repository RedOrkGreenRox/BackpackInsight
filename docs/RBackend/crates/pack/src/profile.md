# [pack/profile.rs](/RBackend/crates/pack/src/profile.rs)

## Назначение
Запись/чтение FlatBuffer `BIPR` (ProfileView): `ProfileViewPack`, `ProfileHeroPack`, `ItemView`, `HeroView`, `SkinList`.

## Ключевая функциональность
- `build_profile_view_bytes(pack)` → `Vec<u8>`.
- `read_profile_view_bytes(bytes)` → `ProfileViewPack`.
